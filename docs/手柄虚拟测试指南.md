# 手柄状态页 · 虚拟手柄测试指南

不接真手柄也能完整验证「手柄状态」页。本指南的每条命令都在本仓库里真实跑通过，
配套脚本位于 `scripts/`。原理：通过 `/dev/uinput` 造出内核级虚拟手柄，
对应用来说与真实手柄无异（热插拔事件、输入读取、力反馈上传全部走真实内核路径）。

## 0. 前置条件

```bash
# 当前用户能写 /dev/uinput（加入 input 组后重新登录）
ls -l /dev/uinput
groups | tr ' ' '\n' | grep -x input
```

## 1. 创建虚拟手柄

```bash
# 前台（Ctrl-C 退出即销毁设备）
python3 scripts/uinput_pad.py create --name "测试 Pad" --id 045e:02dd

# 后台必须用管道喂 stdin，直接 Popen/&,stdin EOF 会让设备立刻消失
sleep 900 | python3 scripts/uinput_pad.py create --seconds 850 --name "手柄A 测试" --id 045e:02dd
```

`--id` 可选预设（命名协议与应用右下角卡片一致）：

| --id | 模拟设备 |
| --- | --- |
| `045e:02dd` | Xbox One 手柄 |
| `045e:028e` | Xbox 360 手柄 |
| `054c:0ce6` | PS5 DualSense |
| `057e:2009` | Switch Pro |
| `--no-ff` 标志 | 无 `FF_RUMBLE` 能力的设备（验证振动组整体置灰 + 原因文案） |

多开几个 `create` 即得多手柄，观察右下角计数卡片与页内设备下拉是否同步增减。

## 2. 注入输入

```bash
# 摇杆（ABS_X 0..65535，50% = 32767）、扳机（ABS_Z 0..1023，60% = 614）
python3 scripts/uinput_pad.py inject --node /dev/input/event24 --event abs:ABS_X:53000
python3 scripts/uinput_pad.py inject --node /dev/input/event24 --event abs:ABS_Z:614

# 按键（只发按下不发抬起 = 保持高亮，用于截图对比）
python3 scripts/uinput_pad.py inject --node /dev/input/event24 --event key:BTN_SOUTH:1
python3 scripts/uinput_pad.py inject --node /dev/input/event24 --event key:BTN_SOUTH:0
```

注意：evdev 在 `SYN_REPORT` 才批量交付，`inject` 脚本已处理；连续注入后留 0.3s 再读页面。

## 3. 振动（力反馈）链路测试

`uinput_pad.py create` 默认自带 FF 服务循环，应答内核的 `UI_FF_UPLOAD`/`UI_FF_ERASE`，
可完整走通「应用 → `/dev/input/eventN` → evdev → uinput 内核回环」：

```bash
# 1) 逻辑层单元 + 回环集成测试（需先有任一 FF 手柄在系统里）
cargo test 振动上传回环 -- --ignored

# 2) 页面运行时验证：选中该手柄 → 按住「按住振动 · 左马达」→ 日志出现
#    [振动] 开始 · …，松开出现 [振动] 停止 · …；连按 1s 自动停、2s 硬停同理
```

## 4. 读数对照（键程当量）

| 注入值 | 页面应显示 |
| --- | --- |
| `abs:ABS_X:32767` 或 `0/65535` | 50% / 0% / 100% |
| `abs:ABS_Z:64`（0..1023 量程） | 6% |
| `abs:ABS_Z:512` | 50% |

两台手柄注入不同值、用页内下拉切换，读数应**跟随所选设备**变化（不会串读）。

## 5. 无设备 / 拔出空状态

杀掉所有虚拟手柄即得空状态（真拔真手柄同理）：

```bash
pkill -f "uinput_pad[.]py"
```

页内应显示空状态图标 +「未连接手柄」，右下角卡片同步归零并弹断开通知。

## 6. 清理

```bash
pkill -f "uinput_pad[.]py"     # 销毁全部虚拟手柄
pkill -x proton-launch          # 关闭被测应用（关闭即彻底退出，不留后台）
```
